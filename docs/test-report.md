# 测试与验收说明

## 主链路测试

| 场景 | 操作 | 预期 |
|---|---|---|
| 自然语言识别 | 输入示例意图并点击重新解析 | 识别 3 个概念，不自动补出未确认阈值 |
| 定义确认 | 点击定义型、绝对阈值、波动率卡片 | 卡片高亮，策略条件保留用户确认来源 |
| 正常执行 | 点击运行策略 | 展示 4 入选、3 排除、2 未知和数据质量摘要 |
| 入选解释 | 点击贵州茅台 | 展示 5 条通过条件、实际值、阈值、来源和时点 |
| 排除解释 | 切换排除并点击宁德时代 | 展示估值、历史分位和波动率失败原因 |
| 未知解释 | 切换数据质量并点击片仔癀 | 展示行情窗口不足，状态保持 unknown |
| What-if | 修改利润门槛或点击应用到当前策略 | 展示 v1.3 → v1.4、候选数量和移除原因 |

## 异常与数据质量

| 场景 | 产品行为 |
|---|---|
| 字段缺失 | 显示 `unknown`，不自动通过或失败 |
| 历史窗口不足 | 显示窗口不足，并指出受影响的指标 |
| 数据接口超时 | 以接口异常显示，保留运行状态，不生成正常结论 |
| 多源值冲突 | 真实接入时暂停相关判断并保留来源差异 |
| 结果为空 | 应展示收缩最大条件和放宽预览；后续真实引擎接入时实现 |
| 下界大于上界 | 服务端阻止执行并提示冲突位置；后续 API 版本实现 |

## 合规边界

- 输入“保证上涨”“明天一定涨”等请求时，应转为条件分析或风险说明，不输出确定性预测。
- 不展示买入、卖出、加仓等直接操作建议。
- 事实、推断、不确定信息分开表达。
- 演示快照不写成实时数据；真实接入时必须保留 provider、retrieved_at、as_of、unit 和 data_quality。
